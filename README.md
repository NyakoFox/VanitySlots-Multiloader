# VanitySlots Multiloader

This project was an attempt at a multiloader VanitySlots rewrite, providing releases for both Fabric and NeoForge.

Unfortunately, the library which replaced Trinkets -- Accessories -- is a lot heavier and feature-rich than Trinkets,
where some of the VanitySlots features were implemented in Accessories itself. Additionally, I feel as if Accessories
was trying to do too much.

The NeoForge versions of VanitySlots were also not used as much as VanitySlots for Fabric, and the rewrite was
generally less popular. As far as I can tell, this is due to moving to Accessories and requiring more dependencies.
People seemed to prefer the simplicity of the original VanitySlots, so for future updates, I will be returning to
using Trinkets for Fabric, and dropping NeoForge support once more.
